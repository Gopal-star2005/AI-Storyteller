## 📘 Overview
**AI Visual Storyteller** is an intelligent, non-human storytelling system that emulates human creativity using modern **multimodal generative AI**.
It converts simple prompts into immersive stories enriched with **AI-generated images**, **downloadable PDF books**, and **audio narration**, demonstrating a complete real-world AI content creation pipeline.

---

## 👤 About the Project
This project is designed to showcase **end-to-end Generative AI orchestration**, focusing on:
- Secure API handling  
- Modular and scalable architecture  
- Multimodal AI pipelines (text, image, audio)  
- Production-ready deployment exposure  

All secret keys have been **intentionally removed** and must be configured via environment variables, making the repository **safe for authors and contributors**.

---

## 🚀 Workflow Overview
1. User provides a **story prompt**
2. Gemini AI generates a **creative narrative**
3. Context-aware images are generated
4. Story is compiled into:
   - 📄 PDF format
   - 🔊 Audio narration
5. NGrok exposes the application via a **public link**

---

## 📂 Output Formats
- ✅ Story PDF (downloadable)

- ✅ Generated images
